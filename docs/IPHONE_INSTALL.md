# iPhone 安装说明

1. 使用 iPhone Safari 打开 `https://qwertyoooo44-bit.github.io/word-siege-tem8/`（不要用微信内置浏览器）。
2. 点击底部分享按钮。
3. 点击“添加到主屏幕”。
4. 开启“作为网页 App 打开”（若系统提供该选项）。
5. 从桌面图标进入。
6. 测试键盘是否遮挡单词。
7. 测试美式系统发音是否播放。界面音标为 UK IPA，与系统语音不一定是同一口音。
8. 完成一个正式单词的七关。
9. 关闭后重新进入，确认进度恢复。
10. 开启飞行模式，确认已缓存内容可以继续使用。

清理 Safari 网站数据会丢失学习记录，请先导出 JSON 备份。
本应用没有账号、广告或云同步。
真实 iPhone 验收必须由用户实际操作后才能标记 PASS。
